# Homelab GitOps

Declarative Kubernetes configuration reconciled by Argo CD.

Argo CD and the cluster networking bootstrap are declared in [nix-config](https://github.com/mitschwimmer/nix-config). Application configuration belongs here. Bootstrap manifests and operating instructions will be added through a pull request.

This repository is public. Keep tokens, passwords, private keys and plaintext Secret resources out of Git.
